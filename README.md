# 📈 Stock Market Analysis Dashboard

A Data Analytics project using **Python (Pandas)** and **Tableau** to analyze stock market data and build an interactive dashboard.

---

## 📌 Project Overview

This project analyzes historical stock data of six companies:

- Apple
- Facebook
- Google
- Nvidia
- Tesla
- Twitter

Python is used for data preparation, and Tableau is used to create interactive visualizations.

---

## 🛠️ Tools Used

- Python
- Pandas
- Tableau Public
- Jupyter Notebook

---

## 📊 Features

- 50-Day & 200-Day Moving Average
- Price Change Analysis
- Volume Analysis
- Percentage Change Calculation
- Interactive Tableau Dashboard
- Company Filter
- Date Range Filter
- KPI Cards
